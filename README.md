# Gaming Web

Portafolio web dedicado al mundo de los videojuegos y los esports.

## Descripción

Este proyecto fue desarrollado como parte de la formación en Desarrollo Web. Incluye cinco páginas con diseño responsive, navegación con Bootstrap, carruseles de imágenes y estilos personalizados con CSS.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Git y GitHub

## Páginas del sitio

- Inicio
- Sobre mí
- Proyectos
- Servicios
- Contacto
